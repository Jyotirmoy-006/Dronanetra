# VRDE 180HP Aero Engine 3D Digital Twin Component Package

This standalone package contains the 3D model component for the **DRDO VRDE 180HP 4-Cylinder Inline Aero Piston Engine**.

### Quick Start
1. `npm install three lucide-react`
2. Copy `components/` into your project's `src/components/`
3. Copy `public/brushed_metal_bg.png` into your project's `public/`
4. Import `<InteractiveEngine3D />` in your page or view.

See [INTEGRATION_GUIDE.md](./INTEGRATION_GUIDE.md) for full step-by-step instructions, props API, and code snippets.
See [examples/Engine3DExampleUsage.jsx](./examples/Engine3DExampleUsage.jsx) for a plug-and-play working example page.
